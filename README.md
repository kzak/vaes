# VAEs - VAE Implementations

Implementation of Variational Autoencoder (VAE), β-VAE, β-TCVAE, and Sparse VAE using PyTorch. Provides a scikit-learn-like interface for easy training and inference.

## Installation

```bash
uv add https://github.com/kzak/vaes.git
```
